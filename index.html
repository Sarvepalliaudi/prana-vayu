02 / Systems Engineering Lab

Rust Domain Modeling & Type Safety

In PRANA-VAYU, critical business decisions and state transitions are handled by a dedicated Rust crate (crates/prana-core), preventing runtime panics, invalid coordinate pairs, and illegal lifecycle jumps.

crates/prana-core/src/severity.rs Type-Safe Severity 
/// Operational severity classification for localized air pollution incidents.
pub enum Severity {
    Moderate = 1,
    High = 2,
    Severe = 3,
}

impl Severity {
    /// Protocol response urgency window (15m, 60m, 360m).
    pub fn response_window_minutes(&self) -> u32 {
        match self {
            Severity::Severe => 15,
            Severity::High => 60,
            Severity::Moderate => 360,
        }
    }

    pub fn requires_immediate_escalation(&self) -> bool {
        matches!(self, Severity::Severe | Severity::High)
    }
}
crates/prana-core/src/lifecycle.rs State Machine 
/// Strict incident lifecycle state transitions:
/// Reported -> Validated -> Assessed -> ResponseActive -> Documented -> Resolved
pub enum LifecycleState {
    Reported,
    Validated,
    Assessed,
    ResponseActive,
    Documented,
    Resolved,
    Archived,
}

impl LifecycleState {
    pub fn can_transition_to(&self, next: LifecycleState) -> bool {
        match (self, next) {
            (s, n) if *s == n => true,
            (LifecycleState::Reported, LifecycleState::Validated) => true,
            (LifecycleState::Validated, LifecycleState::Assessed) => true,
            (LifecycleState::Assessed, LifecycleState::ResponseActive) => true,
            _ => false, // Backward or illegal jumps forbidden
        }
    }
}

04 / Security & Reliability

Defense-in-Depth Engineering Principles

Security and operational resilience are woven into the system from protocol design to cloud execution.

Input Boundary Sanitization

Strict server-side and Rust domain validation limits notes to 3000 chars, zones to 180 chars, and ensures coordinate symmetry (both lat & lng must be present).

Fail-Closed 503 Handling

On database or runtime errors, the API fails closed with HTTP 503 without leaking Python stack traces, AWS account numbers, or table metadata.

Least-Privilege IAM

The Lambda execution role is strictly scoped to GetItem, PutItem, and Scan on the specific DynamoDB table ARN and model invoke ARN.

No Secrets on Client

Gemini and AWS credentials reside exclusively in server-side environment variables. The web console operates safely in local mode without credentials.

Sensor Reading Integrity

The platform explicitly displays PM2.5, PM10, NOx, and VOCs as NULL / UNMEASURED unless certified physical sensors are attached, preventing fabricated metrics.

Volunteer Safety Protocol

Guidance emphasizes physical separation (120m cordon, 15m hose dousing). Volunteers are explicitly advised never to confront operators or enter smoke.
